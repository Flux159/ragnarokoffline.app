A security update: the app now runs on Electron 44.

## Fixes
- **Electron 44 (security):** the app moves from Electron 33, which is no longer supported, to Electron 44 (Chromium 152). This fixes a flaw in the Brotli decoder (CVE-2026-111497) that a malicious server could reach when you join someone else's world. On Linux in a Wayland session, the app now runs as a native Wayland app; `--ozone-platform=x11` still picks X11. Thanks @akreao. (#715)
