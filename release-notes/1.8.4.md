Friends can now join with their own game files, and mods can add extra storages.

## New

- **Join with your own game files.** Settings → Multiplayer → Join a friend has a new *Use my own game files* option: if you've set up a client in your own app, the game reads its GRFs from your disk instead of downloading them from the host, so hosts can run "pure" servers without sending gigabytes of data. Hosts get a matching setting to keep their own files. Both are off by default, and joining works as before unless you turn them on. Thanks @Flux159. (#765)

## Modding

- **Mods can add storages.** A mod can ship `conf/inter_server.yml` to add a second storage that an NPC opens with `openstorage2`, or to rename or resize the main one. The app checks each entry before merging it, so a mod can't point a storage at the wrong table or past the server's storage limit. Thanks @Flux159. (#761)
