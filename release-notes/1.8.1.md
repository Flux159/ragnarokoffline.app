## Fixes

- **Graphics+ "Not loaded":** in 1.8.0, Settings → Mods showed Graphics+ as not loaded, with the message that its `screen_effects` setting had an over-long label or description. The new Screen effects switch's description was longer than the app allows for a mod setting, so the app refused the whole mod. It's shorter now and Graphics+ loads as before, Screen effects switch included. A new test reads every bundled mod's manifest the way the app does, so a mod the app would refuse can't ship again.
