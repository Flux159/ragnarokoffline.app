Mods can now add their own selection boxes, and AI agent windows no longer play with stale files after a mod update.

## Modding
- **Mods can add selection boxes:** a mod's `selectpackageitem` table is now added to the client's own instead of replacing it, so a box a mod adds can open the same pick-one window as the Booster costume boxes. Boxes the client already knows keep their own choices. Thanks @akreao. (#704, roBrowserLegacy#232 via #705)

## Fixes
- **AI agents see your mod changes too:** each AI agent's game window keeps a file cache of its own, and it now drops it when your mods change, the same way your own window does. Before, an agent could keep playing with files from before a mod update, such as an item table that had since been fixed, and lose every item name in it. Thanks @LilArt420. (#706)
