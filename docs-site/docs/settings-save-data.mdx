# Settings: Save data

Your characters and accounts, and the folder everything lives in.

## Back up

Writes the whole database to a file you choose — every account, character,
item, guild and storage, for the era you are on.

Players are briefly disconnected so their latest state is saved consistently.
That is a few seconds, not a stop.

Worth doing before an app update, before enabling internet hosting, and before
any experiment you would mind losing.

## Restore

Replaces the current database with a backup file, and **keeps the game stopped
until you restart it**. A backup of the database it replaced is kept, so a
restore is itself undoable.

An untested backup is not a backup. Restoring one into a throwaway install once
is worth the five minutes.

## Open data folder

Opens the folder holding everything the app keeps: characters, settings, logs,
crash reports and staged backups.

Useful for attaching a log to a bug report, or copying a backup somewhere safe
by hand. See [Installing](./installing) for the path on each platform.

## Copying diagnostics

Not on this page — it is in the app's own menu — but this is the place to
mention it. **Copy diagnostics** collects the app version, your settings, the
server logs, any preserved crash reports and the sharing log into one block of
text you can paste into a bug report.

It never includes passwords or invitation tokens.
