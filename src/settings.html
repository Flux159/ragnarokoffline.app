Game era

Which rules the server runs

Each era keeps its own characters. Switching does not convert them — your other era's characters stay where they are and come back when you switch back. They cannot be shared: pre-renewal stops at level 99 and has no third or fourth jobs. Switching restarts the server.

Game text

The app ships an English translation and lays it over your client's own files. Turn it off and the game reads the text your client came with, which is what you want if that client is not Korean — a Latin American one is in Spanish and Portuguese already.

Western covers Latin American, international, Brazilian and European clients. Korean is for kRO. The two differ only in how the client's text is decoded, and the wrong one turns every accented letter into gibberish, so pick the one that matches the client you downloaded. Changing this rebuilds the assets and restarts the server.

Client version

Which client the server talks to, named by the date of the client it matches. The server and the game window always change together — a client and server a version apart cannot talk at all. Your characters are kept.

Leave this on the default unless something is wrong. A newer version uses newer windows and needs client files at least that new. Experimental means it builds and starts, but nobody has played it through. Changing this rebuilds the assets and restarts the server.

Server clock

The clock the game server keeps. War of Emperium, events that happen at a set time, daily resets and mods that follow the time of day all go by it. It follows this computer unless you choose a zone — for a server you share with friends elsewhere, pick the one most of you live in. Changing this restarts the server.

Startup

For anyone who changes settings more often than they play. With this on, launching opens Settings and nothing else — the server does not start on its own, so press Start and then Open game under Server when you want to play. Leave it off and launching goes straight to the game, which starts the server itself.

Internet sharing

Share this running world with friends outside your local network. Prepare the account safeguards once, then choose Share with friends.

This one-time preparation protects the server and saves a backup. Players disconnect briefly while it restarts. Existing game accounts and characters are preserved.

    Check the account safeguards if sharing asks you to prepare the server. Then choose Share with friends below.

    Play together over the internet

    Your friends open an invitation in their browser and join your server. They do not install the app. Keep this computer awake and the app open while playing together.

    Share creates a temporary invitation link automatically. No Cloudflare account or token is needed. Cloudflare Quick Tunnels are for testing only: they have no uptime guarantee and allow at most 200 requests in flight at once across the tunnel. This is a simultaneous request limit, not a total request allowance or player count; busy asset loading can hit it.

    A temporary link changes every time you start sharing. Cloudflare hands out a new trycloudflare.com address each time, so stopping the app, restarting the server or using Repair means sending your friends a new link. The invitation itself is kept, so only the address moves.

    For a link that stays the same, connect a Cloudflare account below and use your own domain. A named tunnel keeps its address across restarts, and with the saved invitation the whole link stays valid until you choose Create a new link. It needs a free Cloudflare account, a domain on it, and an API token.

    For regular hosting, connect your Cloudflare account and use a named tunnel with your own domain below. Named tunnels do not have the Quick Tunnel 200-request limit and work behind NAT without port forwarding.

    Use a named tunnel for regular hosting

    Use an unused hostname on an active Cloudflare domain. Create a scoped API token with Zone → Zone → Read, Zone → DNS → Edit for that domain and Account → Cloudflare Tunnel → Edit for its account. This is an API token, not a tunnel run token.

    Connect creates a dedicated tunnel and DNS record. The API token is used only during setup; the app saves the tunnel credential in your operating system’s secure password storage. The Cloudflare helper downloads automatically.

    Let friends sign in with Google or Apple

    Optional. With your own OAuth client from Google or Apple, invited friends can sign in with that account instead of a game password. Nothing changes until you add one, and password accounts keep working. It needs the fixed hostname above: Google and Apple only send people back to an address registered in advance. See Sign in with Google or Apple in the friends-sharing guide for how to make the keys.

    Manage invitations and connection

    Forgetting removes the saved credential. Remove the stopped tunnel and DNS record separately in your Cloudflare dashboard.

    Copy diagnostics includes the Cloudflare helper version and checksum verification. Keep the app updated: Cloudflare supports helper versions within one year of its most recent release.

    How long a link keeps working, in days. 0 means it never expires — it lasts until you replace it or stop sharing. This is the invitation, not the tunnel: Cloudflare imposes no limit of its own, and a named domain does not change it. Replace invitation revokes every existing link immediately, and stopping sharing ends them all. Applies to the next invitation you create.

    Mods that change command permissions — player-commands, for example — apply to invited friends too, so anyone with your link gets whatever commands you granted. Only people holding a current invitation can reach the server at all.

    Hosting on a separate internet server is another option, with your own DNS and HTTPS/WebSocket setup. That setup is manual; a DNS record alone does not make a server behind NAT reachable.

    Accounts

    Manage accounts on your own running server. Renewal and pre-renewal have separate accounts and passwords. Changes disconnect current players and restart game services; account IDs, privileges and characters are preserved.

    Owner only disables _M / _F signup. Existing accounts keep working. This policy applies to both eras. Apply and restart to change it. Sharing a link keeps whichever you choose: the invitation already gates the login server, so friends can sign up at the login screen with _M / _F. Choose owner only if you are hosting something larger than a group of friends.

    Choose Refresh to load the current era

    Use 8–23 printable ASCII characters, including letters, numbers, spaces and punctuation, and not the account name itself. The game protocol limits password length; longer or non-ASCII passwords cannot be accepted here. Passwords are never included in diagnostics. A GM or admin account needs a password meeting these rules before internet hosting — you do not have to disable it.

    Character deletion needs a birthday on the account.

    The game asks for the account's birthday before it will delete a character. Accounts created before this app started storing one have nothing to match, so the prompt refuses every answer that can be typed. This writes 1 January 2000 to those accounts and leaves any that already have a birthday alone. Enter it as 20000101 when the game asks. To delete a character: choose Delete, wait out any countdown on the slot, then choose the final delete and enter the birthday.

    Choosing Delete does not remove the character. It queues it and starts a countdown on the slot, and only the final delete after that countdown removes it. A day after it is requested is Ragnarok's own behaviour, and the countdown is what lets you cancel a deletion you did not start — keep it if friends can reach your server. As soon as the birthday is entered removes the wait, so the two clicks run back to back. Either way the birthday is still asked for, and a character in a party or guild is still refused. Applying restarts game services.

    Create an ordinary player account with the password entered above. Use 4–23 letters, numbers, underscores or hyphens, without an _M or _F suffix.

    Save data

    Characters & accounts—
    One .sql file with the characters and accounts of both eras, renewal and pre-renewal. Your settings and mods are not in it: use Back up everything for those. Backing up disconnects players for a moment. Restore shows what the file holds and puts back the eras you choose, keeping a copy of what is there now. An older .sql with one era in it restores into the era you have set.

    Everything

    One file with both eras' characters and accounts, your settings and your installed mods, to keep or to move to another computer. Restore everything shows what it holds and puts back the parts you choose, saving everything as it is now first. It never contains your sharing or Cloudflare credentials, and your game client's files are not copied. It does contain your accounts' passwords, so keep it private.

    Restore

    What you leave unticked stays as it is now. Everything as it is now is saved first, and you will be shown where. The server restarts and anyone playing is disconnected.

    Tools

    Population

    They walk, fight, sit and open vending stalls, and they never touch your characters or your save. They appear only on the maps you and your friends are actually standing on. How busy scales the server's own spawn tables, so the world keeps the shape it was authored with and only its crowding changes. In towns, In fields and In dungeons each take a share of that for one kind of map: 100% is all of it, 0% leaves those maps empty (towns at 0% have none of the fake players' own vending stalls either; a mod's market, such as prontera-vendors, follows that mod's settings). Limit is a safety ceiling across every map at once, and in a solo game it never comes into play. How busy above 50 can make the server sluggish on a computer with less than 8 GB of RAM. Companions: with Free choice the Companions panel drafts any job at any time. Hired makes a companion something you pay for: only jobs of your own class tier, at your level, for the fee per level and/or the item set here, either from the panel or from a Companion Recruiter standing beside each town's healer. Calling back a companion you already have is always free. Weapon rules is a choice between realism and convenience. Off (the default), companions and other fake players use every skill they have whatever they are holding. On, they follow the same weapon rules you do, and a skill their weapon can't use is skipped until you trade them a weapon that can. Companion inventory is the same choice for items. Off (the default), companions carry a free supply of potions, arrows and gemstones that never runs out. On, a companion owns its bag: it drinks, fires and casts with what you trade it, a skill that costs an item waits until it has one, and the bag is kept with the companion between sessions.

    Loot

    Without this, fake players leave every drop on the ground. With it, they walk over and pick up what their own kills dropped, the way a player would. For each drop they decide once whether they want it: Picks up common drops is how often they bother with an ordinary one. A drop is rare when it is a card, or the monster drops it at most as often as Rare from; those they want Picks up rare drops of the time, very likely but not certain. Rare drops are fetched straight away, even while being hit, as long as their HP is above Rare mid-fight above. Everything else waits until nothing is attacking them, and when the fight is over they forget it with the Forgets after a fight chance. A drop they have not reached after Gives up after is left behind (rare ones get twice as long). Looks around is how many cells away they notice their drops. Companions in your party are not affected: what they kill is yours to pick up. Fake players' bags are not saved, so what they loot is gone when they leave.

    Rates
    
  
    
    
    
    
    
    
    
    
    
    Monster population multiplies the counts in the server's
       spawn tables: 2x is twice as many monsters on a map, 4x four times as many.
       Spawns that ask for a single monster are left alone, so MVPs stay unique.
       Unlike the rates above this one stops at 10x — every extra monster is one
       more the server has to think for. It is read when the maps load, so Apply
       restarts the server and you log back in afterwards.
    
    
    
    
    Both raise only. Attack speed is 190 by default and 199 is
       the server's ceiling — the difference is small but it is the whole gap
       between fast and instant. Stat cap is 99 by default and goes to
       32767; third, baby and summoner classes are lifted with it, and left at
       their own defaults while this is untouched.
    
    
    
    
    
    View distance is how far away the server shows you monsters,
       players and NPCs, for screens wider than 16:9. A wider window already draws more
       of the map; this fills it. It also raises how far a click can walk you, and how far
       monsters see and chase, so that nothing you can see is out of reach and nothing that
       can see you ignores you. Official is the stock game. Wider views mean more
       monsters awake at once, and it applies to your own server only — a friend's
       server uses theirs.
    
    
    
    
    
    
    
      
    
    
    
    Any EXP rate above 1x also lifts the server's
       one-level-per-kill cap, which otherwise discards everything a monster
       gives beyond the level it fills.
    
    
    Rates are written to rAthena's conf/import/battle_conf.txt,
       which overrides the shipped config. Applying restarts the map server, so
       log back in afterwards.
