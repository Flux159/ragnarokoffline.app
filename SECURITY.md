# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >1.0.4   | :white_check_mark: |

The current major version of the library receives security updates. New builds are produced via Github actions immediately after a security PR is reviewed & merged. 

## Reporting a Vulnerability

Go to https://github.com/Flux159/ragnarokoffline.app/security/advisories and click "Report a vulnerability" and fill out the report. Please be descriptive as reports will be used to request a CVE disclosure from Github.
