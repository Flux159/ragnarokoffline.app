# English legacy navigation tables

This optional mod supplies the twelve `krpri` and `krsak` navigation tables
from `ROenglishRE/Addons/Navigation Legacy`. Enable it when an additional
English GRF overrides the working tables from the base client and searches
return no results.

It is off by default because the tables in a player's own client normally
match that client's maps and may contain newer entries. The files are copied
from the repository's pinned ROenglishRE checkout while packaging; no game GRF
is stored or modified here.
